PROBLEM
=================================================================

Original error:
  clang: error: unknown argument: '-fcx-limited-range'

Cause:
  -fcx-limited-range is a GCC-specific optimization flag
  Not supported by Clang (used on macOS)

=================================================================
SOLUTION
=================================================================

Modified: src/Makefile (lines 82-90)

Changed from:
  COPTS = ... -fcx-limited-range ...

To:
  COPTS = ... (without -fcx-limited-range)
  
  # -fcx-limited-range is GCC-only
  ifeq ($(IS_GCC_NOT_CLANG),yes)
  COPTS += -fcx-limited-range
  endif
